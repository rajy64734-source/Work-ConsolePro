# 🚀 Work ConsolePro v1.0

A modern, mobile-first productivity and shift-management utility designed for professionals to seamlessly track work hours, manage schedules, and automate monthly salary computations with precision.

---

## 📱 Interface & UI Showcase

Work ConsolePro features a sleek, distraction-free dark UI tailored for mobile accessibility and high usability.

* **Fixed Timings & Shift Configuration:** Easily configure custom check-in, check-out, and break intervals to match exact professional schedules.
* **Console Dashboard:** Real-time tracking hub featuring instant Check-in/Check-out controls and Overtime (OT) mode toggling.
* **Shift Calendar Integration:** Visual monthly calendar overview tracking present days, absences, and scheduled off days seamlessly.
* **Smart Automation (Auto Mode):** Once enabled, Auto Mode handles shift execution and calculates monthly earnings automatically without manual intervention.

---

## 💡 Core Features
* **Automated Monthly Salary Tracking:** Set your schedule once, and the system automatically tracks and computes earnings for the entire month without disruption.
* **Seamless Time Management:** Built-in tools for managing daily work intervals and overtime effortlessly.
* **Responsive Mobile-First Architecture:** Optimized layout ensuring a smooth user experience across mobile displays.
